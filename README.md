# Automation-of-PKI-System-Using-Python-and-OpenSSL
This project automates the Public Key Infrastructure (PKI) lifecycle using Python and OpenSSL, including Root CA creation, Issuing CA setup, certificate generation, verification, revocation, and CRL management.

## Requirements

- Python 3.8 or above
- OpenSSL installed and configured

## Features

- Root CA creation
- Issuing CA setup
- Certificate generation
- CSR creation
- Certificate verification
- Certificate revocation
- CRL management
- Python + OpenSSL automation

## Folder Structure
pki/
├── pki_automation.py
├── openssl.cnf
├── rootCA/
├── issuingCA/

## Installation

1. Install Python 3.x
2. Install OpenSSL
3. Update OpenSSL path in code
4. Run:

```bash
python pki_automation.py
```
